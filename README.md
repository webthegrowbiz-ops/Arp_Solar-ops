# ARP Solar Energy — six-page website (v2)

A static responsive website for ARP Solar Energy (Delhi), developed by Grow Biz.

## The six main pages
1. `/` — Home
2. `/about.html` — About
3. `/services.html` — Solar Solutions
4. `/projects.html` — Projects (verification pending; labelled illustrative imagery)
5. `/solar-guide.html` — Solar Guide + FAQs
6. `/contact.html` — Contact and solar enquiry planner

Supplementary: `/privacy.html` and `/terms.html`.

## Deployment
Vercel is connected to GitHub `webthegrowbiz-ops/Arp_Solar-ops`. Vercel `vercel.json` sets outputDirectory to `static-site`. Files in this folder are the deployable site.

## Safety / launch notes
- Client logo is the original supplied ARP Solar Energy image.
- Client contact email: `arpsolarenergy3@gmail.com` (provided during onboarding).
- Enquiry form uses `mailto:` (email app required), **not** a backend; user must press Send.
- Project images are labelled illustrative; add verified installation imagery before promotional launch.
- Legal templates must be approved by client.
- Do not present subsidy or savings claims as guaranteed.
- Website footer has the requested Grow Biz™ design attribution linking to `https://thegrowbiz.online`.
